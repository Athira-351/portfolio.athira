# Portfolio Project - Backend Documentation

## Overview
This is the backend part of the Portfolio Project, which serves as the server-side application to handle requests and manage data for the frontend.

## Technologies Used
- Node.js
- Express.js
- Middleware for handling requests

## File Structure
- **src/**
  - **server.js**: The main entry point for the backend application.
  - **routes/**: Contains route definitions for handling various API endpoints.
    - **contact.js**: Handles contact form submissions and related functionality.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the backend directory:
   ```
   cd portfolio-athira/backend
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   npm start
   ```

## API Endpoints
- **POST /api/contact**: Submits the contact form data.
